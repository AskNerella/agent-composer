# Evaluate Agent

| Attribute | Required | Default | Meaning |
|---|---:|---:|---|
| User Task | Yes | — | Original request. |
| Agent Response | Yes | — | Answer being evaluated. |
| Evaluation Criteria | No | Correctness, completeness, relevance, clarity, and actionability | Scoring rubric. |

The configured LLM returns a verdict, score, confidence, reason, and improvements.
