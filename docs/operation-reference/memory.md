# Memory operations

These explicit operations remain available when automatic Remember Conversation is disabled.

| Operation | Attributes | Behavior |
|---|---|---|
| Check Memory | User Task; Max Results=`3` | Finds related solved responses. |
| Retrieve Conversation | Session ID | Returns stored conversation history and solved responses. |
| Delete Conversation | Session ID and/or User Task | Removes matching conversation history and solved responses. |
| Reset Memory | None | Clears the configured Object Store, including traces and A2A snapshots. |
